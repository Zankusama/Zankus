# trigger-negative.md — 触发负用例（不应触发）

> 触发实测：以下输入**不应触发** leader-translator，直接干活或走其他流程。

| # | 用户输入 | 期望行为 |
|:--:|:---|:---|
| N1 | 把这份任务书执行了 | 不触发——NOT for 任务书的执行本身，直接执行 |
| N2 | 你好 / 今天天气不错 | 不触发——纯闲聊 |
| N3 | 帮我改个错别字 | 不触发——非本 skill 范围 |
| N4 | 给我设计一个新 skill（从 0 开始） | 不触发——本 skill 只写任务书不设计 skill（引导去 skill 相关流程） |
| N5 | 一句话说清：把 A 表数据搬到 B 表，下班前完成，跑完发我结果 | 不触发全流程——需求清晰且简单，直接答或给简化任务书 |

## 断言

- 需求清晰且简单（一句话说清目标+约束+验收）→ 直接答或给简化任务书，**不走全流程**（description NOT for 声明）
- 任务书执行本身 / 纯闲聊 → 不触发，直接干活
