# 验收清单（怎么判断这次交接是好的）

> 交接产出后逐条核对（v0.1 主文档已将此节拆分至 references/ 下，原编号 §7）。

- [ ] 下一棒**不用开原会话**就能冷读知道下一步做什么，且**直接开工**、没回来问“背景是什么”
- [ ] 文档**第一行**是「未答问题」，且确实是当前最该被回答的那个（多条时按是否阻塞排序）
- [ ] `KEY_FACTS` 里的每个数字/日期/ID，与对话原文**逐字一致**
- [ ] `CONSTRAINTS` 里的每条约束**逐字**来自用户原话，且带轮次或时间
- [ ] **有路径**的产物以路径/URL 形式出现，不是被复制的正文
- [ ] **无路径**的产物在 `ARTIFACTS` 里标了 `[无路径]` 并逐字内联
- [ ] `UNVERIFIED` 要么非空、要么明确写 `none` 并附“已逐条验证过 X/Y”（⛔ **不要为凑这一项编一条**）
- [ ] `SUGGESTED_SKILLS` 写的是“该用什么能力”，**不绑定某端的调用形态**
- [ ] 文档里**没有任何 key / token / password**；如有替换，**每个替换都带“类型 + 原值用途”**
- [ ] 与“下一棒用途”无关的字段已写 `none（与下一任务无关）` 或删除，**没有为填满而编的段落**
- [ ] 文档**没有膨胀到“它自己就会引发漂移”**——可判定代理：**除 `[无路径]` 段落外，文档里没有任何 >10 行的被复制代码 / 日志块**
- [ ] `./handoff/LATEST` 已指向本文档（否则新会话的 `resume` 只能按 mtime 猜）
