# fm-05 · 生意思维三问：赚不赚钱 / 能不能持续 / 有没有壁垒

> 一句话：任何产品决策拍板前，用生意人的三问压一遍"产品好"的兴奋——先算钱，再看活多久，最后问凭什么是你。
> 来源：体系内自研框架的通用化改写（商业常识层，无单一权威出处；与商业模式画布等通用工具同层，不编造来源）。

## 适用时机

- C类 跨场景组件：S1-S5 拍板前的通用压舱石，尤其 🔴 不可逆决策过闸前必跑（联动 fm-01 各闸关口）
- S4 定价与盈利（主场景之一）：第一问直接对应定价账；最终定价决策需跨部门确认（财务/销售/渠道/管理层）
- S5 上市 GTM 策略：三问黄灯项直接进风险字段与跨部门确认清单
- 条件：决策涉及真金白银的投入/定价/渠道承诺；或用户兴奋于"产品/创意"而未谈钱
- 不适用：纯体验优化、无生意属性的功能决策（可只跑第一问或跳过，跳过要在 DR 里说明）

## 框架内容

### 三问总览

| 问 | 核心子项 | 黄灯信号（出现即需补证据） |
|----|----------|--------------------------|
| 一、赚不赚钱 | 商业模式 / 收入 / 成本 / 毛利 / 回本 | 算不清回本周期；毛利覆盖不了渠道费用 |
| 二、能不能持续 | 竞争壁垒 / 复购 / 品牌力 / 供应链 | 一次性买卖无复购；靠补贴维持销量 |
| 三、有没有壁垒 | 护城河 / 差异化 / 复制难度 | 卖点对手三个月能抄；差异化只停在文案 |

### 一、赚不赚钱（商业模式 / 收入 / 成本 / 毛利 / 回本）

- 商业模式：钱从谁口袋来、为哪一环付费（用户买/渠道赚差价/服务收费）
- 收入：量（预估销量）× 价（到手价，扣渠道折扣与返利后的净价）
- 成本：料工费+物流仓储+渠道费用+营销摊销——漏一项账就全错
- 毛利：净价−直接成本；对照品类大致毛利带判断健康度（不引具体行业数，按本组织口径）
- 回本：前期投入÷单件毛利≈回本销量；再换算成回本周期——算不出回本周期=黄灯

### 二、能不能持续（竞争壁垒 / 复购 / 品牌力 / 供应链）

- 竞争壁垒：这生意被抢走的最快路径是什么？（价格战/同款/渠道关系）
- 复购：用户多久买一次、有没有理由再买（消耗品天然复购/耐用品靠系列与升级）
- 品牌力：用户指名买还是靠货架偶遇；有没有可积累的资产（口碑/内容/会员）
- 供应链：产能、原料、交期是否可控；旺季被挤占怎么办——单点依赖=黄灯

### 三、有没有壁垒（护城河 / 差异化 / 复制难度）

- 护城河：对手进场要付什么代价（资金/时间/关系/技术/牌照）
- 差异化：卖点是否可感知、可验证（用户用得出来，不是只写在详情页）
- 复制难度：对手抄到八成像需要多久、需要什么资源；抄走后我们的下一个动作是什么
- 三问都弱但生意成立的情况存在（拼效率/拼执行）——如实标注"壁垒弱"，不许包装成有壁垒

### 结论口径（三色）

- 🟢 绿灯：三问都有据可答，黄灯项为零 → 照常进闸/拍板
- 🟡 黄灯：存在待补证据的子项 → 带着黄灯项进闸，黄灯项进 DR 风险与假设清单，标注待验证
- 🔴 红灯：账算不过来/回本无望/核心依赖失控 → 建议否决或搁置（联动 fm-01 关口四分类）

## 用法步骤

1. 逐问过子项：九个子项逐条写一句结论，有数据给数据，没数据标 ⚠️——检查点：九项无一空白
2. 算账先行：第一问必须出数（哪怕粗糙区间），不许用定性话术替代算账——检查点：回本周期有数字
3. 标黄灯：按上表黄灯信号标记，黄灯项即"未知信息清单"——检查点：黄灯项进 DR 的风险+假设清单
4. 出三色结论：按结论口径定灯色——检查点：🔴 红灯决策不得直接拍板推进
5. 反方压测：自问"如果三问都答错了，最可能错在哪一问"——检查点：反方意见写入 DR
6. B类加码：S4/S5 的最终决策走跨部门确认（财务/销售/渠道/管理层；销售/市场/供应链/管理层），机制见 fm-06——检查点：确认清单随 DR 归档
7. 落决策记录：三问结论收敛为 DR（fm-02），复盘日期对应首个可验证财测节点

## 已知局限

- 三问是压舱石不是商业分析：深度财务建模/竞争战略分析超出本框架，需要时引入专项工具
- 子项全靠估计时，三问会集体乐观——Confidence 自评低于 50% 的项先补证据再放行
- 壁垒判断严重依赖行业语境：跨行业套用容易误判（快消看渠道与复购，硬件看供应链与技术）
- 无对照实验级效果证据；采纳理由是防"产品自嗨"的结构化自检，不是盈利保证
