# ref-05 上市GTM策略（场景S5·B类）

> 场景：新品怎么上市/先铺哪些渠道/上市节奏怎么排。**B类=到PM职责范围：PM职责内分析做透，最终决策不在PM单人。**
> ⚠️ **最终上市决策需跨部门确认（销售/市场/供应链/管理层）**
> 结构：一、GTM流程检查单 → 二、框架要点（5框架）→ 三、输出模板。

## 一、检查单 · GTM 六步流程

> 用法：按流程走，逐步勾选。**核心项=PM必做**；**协作项=PM提供输入**。

### ① 策略（上市的根本打法）
- [ ] 【核心】一句话上市策略（对谁/主渠道/主打差异点/目标——从DR继承）
- [ ] 【核心】渠道优先级排序（首铺/次铺/暂缓，理由=人群与渠道重合度）
- [ ] 【核心】差异化主张确认（与竞品一句话说清区别）
- [ ] 【协作】管理层对上市目标的确认

### ② 计划（把策略翻译成排期与预算）
- [ ] 【核心】上市节奏表（T-周排期：物料/铺货/传播/动销四条线）
- [ ] 【核心】预算框架（营销/渠道费用/物料三类，示例占位量级）
- [ ] 【核心】目标拆解（首月/首季铺货率与动销目标，⚠️假设标注）
- [ ] 【协作】销售目标与激励方案（销售输入）
- [ ] 【协作】传播预算与排期（市场输入）

### ③ 准备（上市前就绪度）
- [ ] 【核心】渠道就绪（首铺渠道的进货意愿/陈列资源确认）
- [ ] 【核心】物料就绪（详情页/导购话术/陈列物料清单勾完）
- [ ] 【核心】供应链就绪（备货量与交期确认，安全库存规则）
- [ ] 【核心】合规就绪（宣称/标识/备案齐，法务输入）
- [ ] 【协作】培训完成（导购/客服话术培训，销售/客服执行）

### ④ 执行（按节奏上线）
- [ ] 【核心】铺货执行跟踪（日/周铺货率 vs 计划）
- [ ] 【核心】传播执行跟踪（上线时点与内容 vs 计划）
- [ ] 【协作】现场问题快速响应（渠道断货/陈列问题，销售执行）

### ⑤ 跟踪（数据说话）
- [ ] 【核心】核心指标看板（铺货率/动销率/复购/退货率，口径定义）
- [ ] 【核心】周复盘机制（对计划找差异，差异原因写明）
- [ ] 【协作】渠道库存与动销数据回流（销售/渠道输入）

### ⑥ 复盘（上市后固定动作）
- [ ] 【核心】AAR 四问复盘（详见 fm-04复盘框架.md，30/90天各一次）
- [ ] 【核心】假设-结果对照（立项时 ⚠️ 清单逐条核）
- [ ] 【核心】迭代/止损建议（下一版 DR 输入）
- [ ] 【协作】渠道返利/费用核销核对（财务/销售输入）

## 二、框架要点（5框架）

1. **GTM 框架**（来源：Go-To-Market 方法论通用体系）。要点：GTM=市场选择（Who）×价值主张（What/Why）×渠道打法（Where/How）×节奏（When）四件套；四件没想全=策略漏风，先补齐再排期。
2. **4P 组合**（来源：McCarthy 4P）。要点：上市是把产品/价格/渠道/促销四要素一次性对齐的动作；上市前逐 P 自查——Product 就绪度、Price 与渠道价差、Place 首铺与陈列、Promotion 传播与转化路径。
3. **STP**（来源：Philip Kotler 营销管理体系：Segmentation/Targeting/Positioning）。要点：上市策略的"对谁/打哪"必须能一句话说清（细分-目标-定位三连）；说清 STP 再谈渠道与预算，顺序不能反。
4. **渠道策略矩阵**（来源：渠道管理通用方法）。要点：按"人群重合度×渠道运营成本"对候选渠道排序——重合度高成本低=首铺，高成本低重合=缓投；多渠道并行前先在一个渠道跑通最小闭环。
5. **上市里程碑**（来源：项目管理通用方法）。要点：T-周倒排（T-8 物料齐→T-4 渠道确认→T-0 上线→T+2 首波动销盘点→T+8 复盘）；里程碑每项有负责人与完成判据，延期触发应急预案。
6. **价盘一致性与窜货管理**（来源：渠道管理通用实践；B1 点名）。要点：多渠道并行先定**价盘纪律**——各渠道成交价带与促销底线一致，防"线上打穿线下"；窜货=货流向非约定区域/渠道（通常因价差+返利钩子），治理靠价差设计+编码追溯+返利挂钩，不靠罚款口号；价盘失控是渠道资产流失的最快路径（毛利红线见 ref-04）。

**B类边界行为**：PM 职责内=上市策略、计划、就绪度核查、跟踪与复盘设计；跨部门确认项=最终上市时间与规模（管理层）、渠道执行（销售）、备货（供应链）、传播投放（市场）。输出一律附标注：**最终上市决策需跨部门确认（销售/市场/供应链/管理层）**。

## 跨职能约束维度（决策点检查；B 类从"输出后标注"升级为**输入前检查**）

> 用法：每到一个决策点，先扫 7 维（≤4 条入约束卡）；每维回答"PM 要回答什么+谁拍板"。
> 品牌资产=第 7 维（总案 D5 层1：品牌作为产品决策的受影响维度，如"降价伤不伤调性"在此检查）。

| 维度 | PM 要回答什么 | 谁拍板（B 类标注） |
|---|---|---|
| 法规合规 | 宣称/备案/标签边界在哪？ | 法务/合规 |
| 渠道适配 | 各渠道接不接、要什么条件？ | 销售/渠道 |
| 促销空间 | 促销价盘与费比空间多少？ | 销售+财务 |
| 库存动销 | 备货/清仓水位与动销口径？ | 供应链 |
| 成本 | 完全成本与量产达成？ | 财务/供应链 |
| 财务 | 毛利口径与回本口径？ | 财务 |
| **品牌资产（第7维）** | 此动作对品牌资产/调性/价格形象的影响？ | 品牌部/CMO |

## 三、输出模板

### S5 台面模板（四区；[完整]/[轻]/[快轨] 徽章路由，机器校验 check_output.py）
```
[完整] ｜ S5 上市（示例占位）
（开场人话：这是新品上市级的决定，渠道合约与备货沉没成本退不回——我先跟你确认<X>）
【建议】<明确推荐+渠道矩阵依据>（置信度：高/中高/中 · 一句依据）
下一步（你）：<第一动作（如：确认首铺渠道进货意愿与陈列资源）>
【为什么】
1. <可验证事实/数字 → 所以…>（如：人群与首铺渠道重合度高 → 所以单渠道首铺小步快跑）
2. <论据>（完整态 ≥2 条）
【为什么不选别的】
- 三渠道同步铺开：死于执行力与备货跟不上（先在一个渠道跑通最小闭环）
- 推迟上市：代价是窗口期让给竞品（示例占位）
【换挡条件】若<信号+阈值，如首铺渠道人群重合度实测偏低> → 结论改为<选项>；复盘日 <YYYY-MM-DD>
【最可能翻车的点】<最强反方（具体条件+可反驳出口），如：供应链断货则上市节奏全盘落空——盯备货交期确认单>——不同意就怼，我当场对
（档案已存：./决策记录/DR-YYYYMMDD-xxx.html——9 字段/风险六维/假设/反方/探讨轨迹齐全）
⚠️ 最终上市决策需跨部门确认（销售/市场/供应链/管理层）
```

### S5 决策档案模板（9字段+探讨轨迹+归位，收敛后落盘）
```
# DR-YYYYMMDD-<slug>
- 问题：[示例占位：新品X怎么上市、先铺哪些渠道]（场景S5｜决策者=用户（跨部门确认）｜截止=YYYY-MM-DD）
- 选项：单渠道首铺 / 多渠道同步 / 推迟上市
- 决定：用户拍板原文或推荐倾向（标注"待跨部门确认"）
- 依据：ref-05渠道策略矩阵+里程碑表条目（示例占位）
- 反方意见：最强反方+什么数据会推翻（如：首铺渠道人群与目标人群重合度实测偏低）
- 风险：6维度风险点+验证方式
- 假设清单：⚠️ 首铺渠道转化假设/备货交期假设/传播效果假设——逐条"假设·待验证"
- 复盘日期：YYYY-MM-DD（建议=T+30 与 T+90 两次）
- 状态：草案/已定/复盘/关闭
- 探讨轨迹：初步版→用户反驳（引用用户原话）→结论如何更新；或 用户跳过探讨：原因=X+证据
- 归位：增×渠道/上市 → S5 ｜ 归位成功 ｜ 理由一句话 ｜ 可逆性=🔴/🟢（只读段，收敛闸校验）
⚠️ 最终上市决策需跨部门确认（销售/市场/供应链/管理层）
```

---
适用时机：新品上市、渠道扩张、上市复盘。已知局限：GTM 效果一半在执行组织能力，检查单管不了"执行变形"——用⑤跟踪与⑥复盘回补；首铺渠道选择错误是本场景最贵的错误，宁可小步验证。B类边界：PM不出最终上市结论，只把策略与计划做透。
