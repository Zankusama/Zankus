# ref-04 定价与盈利（场景S4·B类）

> 场景：定多少价合适/要不要涨价做促销价/毛利不够怎么办。**B类=到PM职责范围：PM职责内分析做透，最终决策不在PM单人。**
> ⚠️ **最终定价决策需跨部门确认（财务/销售/渠道/管理层）**
> 结构：一、定价流程检查单 → 二、框架要点（5框架）→ 三、输出模板。

## 一、检查单 · 定价流程（8步，每步核心项+协作项）

> 用法：按流程走，逐步勾选。**核心项=PM必做**；**协作项=PM提供输入**（由职能方确认）。漏标步骤>0 → 属"搁置"：补齐关键输入再定。

### ① 目标（这次定价到底解决什么）
- [ ] 【核心】定价目标唯一主选（利润优先/份额优先/渗透优先/形象锚定，只能主选一个）
- [ ] 【核心】成功判据数字（示例占位：毛利率≥X% 或 渗透店数≥Y，写进 DR）
- [ ] 【协作】管理层对目标的背书输入

### ② 需求（谁买、多想买）
- [ ] 【核心】目标人群支付意愿估计（来源注明：调研/类比/渠道反馈）
- [ ] 【核心】价格敏感度判断（必需vs可选/上瘾性/替代品多少）
- [ ] 【协作】用户调研价格测试数据（调研方输入，有则用）

### ③ 成本（底线在哪）
- [ ] 【核心】单件完全成本构成（料工费+分摊，示例占位）
- [ ] 【核心】盈亏平衡量测算（固定成本÷单位边际贡献）
- [ ] 【协作】精确成本核算（财务/供应链提供）

### ④ 竞争（别人卖多少）
- [ ] 【核心】竞品价格带扫描（直接竞品≥3，含促销常态价）
- [ ] 【核心】本品相对价值声明（凭啥同价/凭啥贵/凭啥便宜）
- [ ] 【协作】渠道竞品动销与折扣情报（销售输入）

### ⑤ 方法（选主定价法）
- [ ] 【核心】主方法选定并说明理由（成本加成/价值定价/竞争导向，三选一为主）
- [ ] 【核心】辅助方法交叉验证（主方法结论与辅助口径打架时写明处理）

### ⑥ 方案（具体价格设计）
- [ ] 【核心】主价格带落位（对标哪个价格带、卡位理由）
- [ ] 【核心】规格价差设计（大小规格/组合装价差逻辑）
- [ ] 【核心】促销价底线（最低促销价=毛利红线，写明）
- [ ] 【协作】渠道价差结构（各级渠道毛利空间，销售输入）

### ⑦ 测算（用数字检验）
- [ ] 【核心】三情景测算（乐观/基准/悲观：销量×价格×成本，示例占位）
- [ ] 【核心】盈亏平衡复核（促销价下打不打得平）
- [ ] 【核心】价格弹性假设显式化（⚠️"假设·待验证"：提价X%预计销量降Y%）
- [ ] 【协作】财务口径复核（财务确认测算模型）

### ⑧ 调整（留好触发器）
- [ ] 【核心】调价触发器（销量/库存/竞品动作到什么阈值触发复议，写进 DR 复盘字段）
- [ ] 【核心】促销节奏表（大促/平销价格纪律）
- [ ] 【协作】渠道调价通知与执行节奏（销售执行）

## 二、框架要点（5框架）

1. **3C 定价三角**（来源：大前研一 3C 模型在定价中的应用：Company/Customer/Competitor）。要点：定价=三方约束的交集——公司成本底线、顾客支付意愿、竞品价格锚；三方数据都齐才能定，缺一方=搁置。
2. **价值定价**（来源：价值定价方法论（Nagle《定价策略与盈利》体系））。要点：价格锚定"顾客感知价值"而非成本——价值=参照品价格+差异化价值±负面价值；适用于有明确差异点的品；配套动作：把差异点翻译成顾客语言并量化。
3. **价格带分析**（来源：零售定价管理通用方法）。要点：先找品类价格带阶梯（低/中/高/超高端的卡位与空档），再定本品卡位；空档≠机会，要看空档对应的人群规模与购买力。
4. **盈亏平衡分析**（来源：管理会计通用方法）。公式：盈亏平衡量=固定成本÷（单价-单位变动成本）；要点：促销价/大规格都过一遍盈亏平衡，防止"卖得越多亏得越多"；可机器化：`python3 "$SKILL_DIR/scripts/calc-pricing.py" --price 牌价 --unit-cost 单位成本 --fixed-cost 固定成本 --channel-fee-rate 渠道费率 --rebate-rate 返利率`（闸口H：**净价=牌价−渠道费用−返利** 的扣减层/三情景/弹性/伪精度护栏 3 条——缺输入拒算，不给编造数字）。
5. **价格弹性**（来源：微观经济学需求价格弹性）。公式：弹性=销量变化%÷价格变化%；要点：弹性>1 提价伤收入、弹性<1 提价增收入；弹性值来自试销或历史调价数据，没有数据就小范围 A/B 试，⚠️假设必须标注"不确定/待验证"。
6. **PPA 价格包装架构**（来源：Revenue Management / RGM 通用实践；B1 织入）。七步精简版：①定价格包结构（好-更好-最好分层）②锚定价设定 ③版本化差异点（什么值得多付钱）④规格梯度（容量/组合装）⑤渠道价差兼容校验 ⑥涨价/降级路径预置 ⑦价盘周监控。要点：PPA 管的是"价格架构"不是单一价格点；适用=多规格/多渠道品类；规格类新决策先做动机消歧（价格点动机归本场景，变体丰富归 ref-02）。
7. **促销 baseline/增量**（来源：促销评估通用方法，纯公共做法；B1 织入）。最小算法：增量销量=促销期销量−baseline；baseline=促销前 4 周均值经季节修正（同店口径）；费效=增量毛利−促销投入，负值=赔本赚吆喝、写进 DR。促销价底线=毛利红线（对照检查单⑥）。数据按本组织口径取数，示例一律"示例占位"。

**B类边界行为**：PM 职责内=定价目标、分析、方案、测算、调价触发器设计；跨部门确认项=最终价格（管理层）、毛利口径（财务）、渠道价差执行（销售/渠道）。输出一律附标注：**最终定价决策需跨部门确认（财务/销售/渠道/管理层）**。

## 跨职能约束维度（决策点检查；B 类从"输出后标注"升级为**输入前检查**）

> 用法：每到一个决策点，先扫 7 维（≤4 条入约束卡）；每维回答"PM 要回答什么+谁拍板"。
> 品牌资产=第 7 维（总案 D5 层1：品牌作为产品决策的受影响维度，如"降价伤不伤调性"在此检查）。

| 维度 | PM 要回答什么 | 谁拍板（B 类标注） |
|---|---|---|
| 法规合规 | 宣称/备案/标签边界在哪？ | 法务/合规 |
| 渠道适配 | 各渠道接不接、要什么条件？ | 销售/渠道 |
| 促销空间 | 促销价盘与费比空间多少？ | 销售+财务 |
| 库存动销 | 备货/清仓水位与动销口径？ | 供应链 |
| 成本 | 完全成本与量产达成？ | 财务/供应链 |
| 财务 | 毛利口径与回本口径？ | 财务 |
| **品牌资产（第7维）** | 此动作对品牌资产/调性/价格形象的影响？ | 品牌部/CMO |

## 三、输出模板

### S4 台面模板（四区；[完整]/[轻]/[快轨] 徽章路由，机器校验 check_output.py）
```
[完整] ｜ S4 定价（示例占位）
（开场人话：这是主力品调价级的决定，价格体系乱了收不回——我先跟你确认<X>）
【建议】<明确推荐+主定价法依据>（置信度：高/中高/中 · 一句依据；测算数字沉档案，台面禁裸百分比）
下一步（你）：<第一动作（如：补竞品常态成交价与支付意愿测试）>
【候选选项】① <卡位中价格带上沿（当前推荐）> ② 低价渗透 ③ 维持现价只调促销
【为什么】
1. <可验证事实/数字 → 所以…>（如：竞品价格带空档+成本底线有据 → 所以卡位中价格带上沿）
2. <论据>（完整态 ≥2 条）
【为什么不选别的】
- 低价渗透：死于弹性无实测数据、跟价风险不可控（缺弹性数据无法比较）
- 维持现价只调促销：代价是价格带空档被竞品占位（示例占位）
【换挡条件】若<信号+阈值，如竞品同步降价> → 结论改为<选项>；复盘日 <YYYY-MM-DD>
【最可能翻车的点】<最强反方（具体条件+可反驳出口），如：竞品同步降价则渗透策略失效——看竞品周跟踪>——不同意就怼，我当场对
（档案已存：./决策记录/DR-YYYYMMDD-xxx.html——9 字段/风险六维/假设/反方/探讨轨迹齐全）
⚠️ 最终定价决策需跨部门确认（财务/销售/渠道/管理层）
进度：第 X 轮 · <当前步骤人话> · 还差：<台账未确认项 or 可收敛> ｜ 本轮跳过：<无 or 跳了什么+一句人话原因> ｜ 假设新增：<N> 项已挂账
```

### S4 决策档案模板（9字段+探讨轨迹+归位，收敛后落盘）
```
# DR-YYYYMMDD-<slug>
- 问题：[示例占位：A品2.0上市定什么价]（场景S4｜决策者=用户（跨部门确认）｜截止=YYYY-MM-DD）
- 选项：中价格带上沿 / 低价渗透 / 维持现价调促销
- 决定：用户拍板原文或推荐倾向（标注"待跨部门确认"）
- 依据：ref-04主定价法+测算表条目（示例占位数字）
- 反方意见：最强反方+什么数据会推翻（如：竞品同步降价则渗透策略失效）
- 风险：6维度风险点+验证方式
- 假设清单：⚠️ 弹性假设/成本假设/竞品不动假设——逐条"假设·待验证"
- 复盘日期：YYYY-MM-DD（建议=价格执行后首个完整促销周期）
- 状态：草案/已定/复盘/关闭
- 探讨轨迹：初步版→用户反驳（引用用户原话）→结论如何更新；或 用户跳过探讨：原因=X+证据
- 归位：改×价格体系 → S4 ｜ 归位成功 ｜ 理由一句话 ｜ 可逆性=🔴/🟢（只读段，收敛闸校验）
⚠️ 最终定价决策需跨部门确认（财务/销售/渠道/管理层）
```

---
适用时机：新品定价、调价、促销价设计。已知局限：支付意愿数据多数组织没有实测值，只能类比+小步测试逼近；本检查单保证流程完整，不保证"算出最优价"。B类边界：PM不出最终价格结论，只把分析做透。
