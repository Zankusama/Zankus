# ref-06 通用组件（C类跨场景·六个组件）

> C类=用户问题不构成完整决策场景，只做组件级提醒：风险提醒/未知信息引导/生意思维三问/身份层/复盘/跨域拆解出口。**只提醒不决策**，不给决策建议、不出 DR，除非用户接着给出完整决策问题（转对应场景）。
> 结构：六组件各含 触发时机/内容要点（标来源）/输出格式；末尾附组件执行检查单。

## 组件① 风险提醒

**触发时机**：每次给建议前过一遍；🔴不可逆决策必跑；涉及安全/合规的问题无条件先提醒、不等信息补齐。

**6 维度清单**（每维：典型风险点举例=示例占位 + 建议验证方式；只列风险点+建议验证，**不替用户做风险结论**）：

| 维度 | 典型风险点（示例占位） | 建议验证方式 |
|---|---|---|
| 法规 | 宣称用语超边界、备案/标识缺失、标签规范 | 查法规原文/合规方复核/小范围法务确认 |
| 市场 | 需求判断过时、季节波动、渠道需求变化 | 看近3周期销售数据/渠道访谈 |
| 竞争 | 竞品跟进降价、替代品截流、对手新品截胡 | 竞品价格带周跟踪/新品监测 |
| 供应链 | 断货、原料涨价、交期延误、库存积压 | 产能确认单/备货交期核对/库存水位 |
| 财务 | 毛利打穿、回本周期拉长、现金流承压 | 三情景测算/盈亏平衡复核（引 ref-04） |
| 组织 | 产线/人力排不过来、跨部门执行走形 | 资源排期确认/执行责任到人（RACI，引 fm-06） |

**输出模板**：`风险点（维度）｜影响程度（高/中/低）｜建议验证/规避动作` 逐条列；无风险的维度写"未命中"。

**事前验尸引导语（🔴不可逆收敛前必加一句）**：问一句"假设一年后这事惨败了，回头解剖，最可能的死因是什么？"——答案按最强反方双要素（具体条件+可反驳出口）写进台面【最可能翻车的点】，完整推演与次级死因沉档案探讨轨迹段；事前验尸产出的"预防动作"并入换挡条件或风险验证方式，不留在口头。

## 组件② 未知信息引导

**触发时机**：影响决策但用户没说的信息——先引导补充，不假设；引导后用户不补充→按**口径唯一化**处理：🔴不可逆决策停住不推演；🟢可逆决策标 ⚠️"假设·待验证"继续且输出顶部高亮假设清单；安全/合规无条件先提醒。不空等。

**决策情境四变量**（情境不落盘，随 DR 草案承载，决策生命周期即其生命周期）：决策目标（解决什么）/ 预算约束 / 时间窗 / 数据缺口。决策权维度已移除——终审权 = 身份层 L1 拍板权字段；流程参与方 = B 类跨部门标注（约束七维含"谁拍板"）。归位后由情境校准调用。

**各场景关键未知信息**（逐场景专列）：
- S1 新品立项：市场规模口径/目标人群画像/竞品对照/渠道适配/成本结构
- S2 组合规划：单品贡献度/增长趋势/产能约束/战略定位
- S3 生命周期：销售增速口径/获客成本/渗透率/利润趋势/复购
- S4 定价：价格带/成本与毛利目标/竞品价格/需求弹性
- S5 GTM：渠道结构/上市节奏/资源预算/物料准备

**输出模板**：`信息点 ｜ 为什么影响决策 ｜ 建议怎么获取` 逐条列；用户已给的信息不重复问。

## 组件③ 生意思维三问（通用化版）

**触发时机**：用户问"这生意值不值/该不该进/划不划算"，或任何决策前快速体检。

**三问展开**：
1. **赚不赚钱**（短期账）：商业模式（谁付钱为什么付）/收入结构（一次还是复购）/成本结构（大头在哪）/毛利水平（对比品类常态）/回本周期（多长、多确定）
2. **能不能持续**（中期账）：竞争壁垒（凭什么别人抢不走）/复购与留存（用完还买吗）/品牌力（主动指名吗）/供应链稳定性（断供风险）
3. **有没有壁垒**（长期账）：护城河类型（品牌/渠道/成本/技术/网络效应）/差异化（可感知吗）/复制难度（对手抄要多久花多少）

**输出模板**：三问各给 提问清单+现状判断句（判断必须标"不确定/待验证"若数据缺失）；三问只做体检提醒，**不出"该不该做"的结论**——那是场景决策（S1/S2）的事。

## 组件④ 身份层（决策前提库固化）

**身份层字段（L0 4 字段 + L1 4 字段，无 L2；schema 唯一口径见 SKILL.md「身份层」）**：
- **L0 基座**（换赛道/换定位才变）：行业 / 品类 / 目标客群 / 公司规模
- **L1 结构**（季-半年，关键决策前重验）：品牌阶段 / 渠道结构 / 拍板权 / 定位禁区

**固化流程**：
1. 会话已载入（已读 `config/local_profile.md` = skill 目录内唯一身份层文件）→ **载入即回显**：profile-check 已打印全文（人话回显稿），AI 逐条念给用户确认「还成立吗」→ 用户确认/纠正后才进场景（v4.3 起：每次会话固定前置，不靠自觉，不回显不得直接进场景提问）
2. 初次使用 → 会话启动时提问固化 L0 4 字段 + L1 4 字段（**必填仅 2 个：行业大类+品类名称**；目标客群/公司规模宽松，用到时现场确认；L1 关键决策前重验），**问句照下方「白话问句脚手架」8 问说——现象问法、标签 AI 整理，用户只答现象**；答不出分层（采集纪律，准确性优先）：能确认才固化；知道谁能确认 → 挂起不猜——字段留空，「待补采：此信息问 ___」只记当次输出/缺失清单、**不写进字段值**（占位写进去会被校验按未固化处理，不干净也不通过）；无从问 → 缺省不填、命中时显式「假设·未验证」——**禁止填充、禁止逼答**。结果写入 **skill 目录内 `config/local_profile.md`**（唯一文件：收到即空模板、填了即本机身份层；`--profile` 或环境变量 `PM_STRATEGIST_PROFILE` 可覆盖）；固化带【固化日期】确认戳 + `> schema 版本：vX.Y.Z`（字段口径版本，与 profile-check.py 的 SCHEMA_VERSION 一致；不随包版本联动，字段没变就不 bump），`python3 "$SKILL_DIR/scripts/profile-check.py"` 校验（闸口C 双闸门：闸A 字段集比对——缺模板字段=升级未迁移 exit 1；闸B 版本戳落后 exit 1；真缺失[键在值空/待固化]列缺失清单 warn 不拦；带戳超期 90 天 exit 1 硬拦附重验提示，逐项重验重打戳后恢复"已固化"资格）
3. **回显确认固定步骤**（只存用户亲口确认的 [stated]；载入回显 / 首采 / L1 补采 / 90 天重验 / 升级迁移 / 升级通道 / 前提打破更新——所有入口共用，非 AI 临场发挥）：**v4.3 起载入即回显**——profile-check 每次运行打印全文回显稿，AI 必须逐条念给用户确认「还成立吗」，确认/纠正后才进场景（不再有"平时戳有效→不回显不问"，回显=每次会话固定前置）；采集/更新时 → 整理待写入字段清单 → **回显整份 profile（含既有字段全文）** → 用户逐条确认/纠正 → 才打戳落盘。**回显不甩字段名——逐条翻译人话**（"第 1 条：主业是大健康养生个护，对吗？…第 7 条：定价这类事你拍板，我记的是'你自己定'，对吗？"），改一条动一条。三级触发（防拖死主流程）：首采/大改/升级/前提打破 → **全量回显**；90 天重验 → 只回显变更字段（≤3 个聚焦问题）；日常载入 → 简短过一遍全文（人话稿逐条确认）
4. **决策情境 + 升级通道**：情境（决策目标/预算约束/时间窗/数据缺口）不写入前提库——当次问、当次用，随 DR 草案承载，决策关闭即过期。披露深度跟**可逆性 × 影响度**走：🔴不可逆 → 四变量缺一问全，缺关键项停住（口径唯一化）；🟢可逆 → 只问命中变量（≤2），其余合理假设 ⚠️ 继续；快轨 → 情境走披露分层低档（目标一句话回显，未知标 ⚠️ 继续），不触发听证会。**升级通道判据**：情境中用户表述**跨 ≥2 次决策仍成立且希望不再重复问** → AI 白话问一句"这件事你两次都这么定了，看着是会一直成立的——要不要我记进你的公司长期档案？要记的话我会整段念给你、你确认过才存" → 用户确认 → 回显确认（步骤 3）→ 归位：按记忆判据核验——命中 L0/L1 白名单字段则入对应位（例："融资续命期还得熬半年"= 品牌阶段 → L1）；命中短期黑名单（价格/毛利/预算等数值）**即使跨 2 次决策也不固化**——升级通道不改变信息本质，只走确认流程
5. **前提打破更新（4 型）+ 升级迁移（第⑤型，v4.3.0）**：① 换公司/换岗 → 全量重采逐字段回显；② 换赛道/重大转型 → 全量重采 + 定位禁区重审；③ 品类扩展 → 增量更新（更新品类 + 新增禁区 + 客群确认，不重问行业/拍板权）；④ 单字段演进 → 单字段更新 + 重打戳；⑤ **升级迁移（schema bump）**：profile-check exit 1（缺键/版本落后）→ 全量回显旧文件全文 → 按新模板字段逐条「还成立吗」→ 补新字段/迁移旧值 → bump 文件内 `> schema 版本` 行到当前版本 → 重打戳。统一流程 = 回显旧 profile 全文 → 逐条"还成立吗" → 更新/保留/删除 → 重打戳 → 记变更原因
6. **疑似冲突核对**（会话中随时触发，不只采集时）：用户表述与已固化 L1 值**语义同域疑似冲突**（描述同一对象域：公司阶段/渠道/拍板/禁区，但字面/维度/程度不同）→ **禁止静默**（不覆盖、不忽略、不当两回事）→ 摆出旧值与新表述 → **白话问一句"你刚说的这个，和我之前记的那个对不上——是同一件事换了种说法、情况真的变了、还是你同时说两件不同的事（比如钱的事和方向的事）？"** → 用户裁决 → 按裁决更新（走 ④单字段演进 + 重打戳）或保留旧值。品牌阶段等**叙事字段允许多维并存**（标签 + 维度限定句，如"增长瓶颈期+财务维度：靠融资续命"），禁止压成单维标签丢维度

**白话问句脚手架（对用户说话的标准句——首采 8 问照读；现象问法，标签 AI 整理）**：

| 字段 | 白话问法（AI 照着说） | 兜底（答不出） |
|---|---|---|
| 行业 | "先简单认识一下：你们公司主业是哪个行业？比如大健康、养生个护、食品、日化这类" | — |
| 品类 | "你们主打的拳头产品是哪一类？举个例子说说具体卖什么？" | — |
| 目标客群 | "这些东西主要卖给谁？大概什么年龄、什么场景下用？" | "想不全没关系，用到再补" |
| 公司规模 | "公司现在大概多大的盘子？人数、年营收说个量级就行，不用精确" | "不知道就跳过，不瞎填" |
| 品牌阶段 | "品牌现在卡在哪个阶段？刚起步、在增长、还是增长遇瓶颈了？现在最头疼的增长问题是什么？钱够烧多久？" | 现象问法——标签 AI 整理，不让用户自己概括 |
| 渠道结构 | "现在主要在哪些渠道卖？线上哪个平台、线下门店/经销商，谁是主力、谁在拖后腿？" | — |
| 拍板权 | "定产品、定价格这类事，最后谁拍板？是你本人，还是上面还有老板/几个人一起定？" | "不清楚先跳过，问明白再告诉我——我不会瞎记" |
| 定位禁区 | "有没有公司碰都不能碰的红线？比如价格底线、功效上不能乱说的、老板明确禁止的方向？" | "一时想不全没事，想到随时补" |

**转述纪律**：profile-check 输出（L0/L1/首采门槛/确认戳/缺失清单等）是给 AI 的机械信号——读后必须翻译成上表白话再对用户说，禁止原样念出字段名与门槛黑话（用户听到的永远是"人话版本"）。

**作用规则**：身份层字段与当前问题**强关联**（如渠道结构与铺货决策）→ 分析做透（A类标准）；**弱关联**（如拍板权确认与单次包装微调）→ 只提醒。判定由 PM 问题与字段的映射决定，输出中注明"本建议已按身份层校准"或"按通用快消语境·待行业校准"。

## 组件⑤ 复盘

**触发时机**：DR 到复盘日期/假设落空/用户要求复盘。

**内容要点**（详见 fm-04复盘框架.md）：
- **AAR 四问**：计划是什么/实际是什么/差异为什么/接下来怎么办
- **假设-结果对照**：DR 假设清单逐条标 应验/落空/待验，落空项写原因
- **决策质量 vs 结果质量**：好决策+坏运气≠错决策（评的是当时信息下的决策过程，不是只看结果）
- **经验沉淀**：把可复用的判断写成一句规则句（`- 经验句：xxx` 裸键格式），**写入 profile 经验句区**（身份段结束后 `## 经验句` 二级标题段，≤5 条 LRU）——写入纪律 = 先回显确认 → 写入；若超 5 条，回显确认淘汰最旧 1 条（移入 DR 归档后删除）。

**输出模板**：`复盘日期 ｜ AAR四问结论 ｜ 假设对照表 ｜ 经验句` + 原DR状态改为"复盘/关闭"。

## 组件⑥ 跨域拆解出口（品牌级战略本体）

**触发时机**：原语齐但对象枚举外——决策直接改动的是品牌本身（品牌重新定位/品牌架构重构等）。

**服务方式（拆解优先）**：
1. 按 100% 规则拆出产品域可执行部分，逐个归位拿弹药（如"品牌年轻化"→拆出 目标人群/产品迭代/价格带 等子决策，各自走矩阵）
2. 战略本体部分 → **纪律服务**：显式假设+最强反方+风险六维（品牌重新定位=🔴不可逆）+ DR9 收尾
3. 显式声明："品牌战略本体超出场景弹药——本 skill 是产品决策军师，不是品牌战略顾问"
4. 转介锚点：Aaker 品牌谱系（品牌资产模型/品牌架构四型）；架构落回产品域的部分（挂主品牌还是子品牌）走 ref-01 品牌架构适配项（层2 定义属性）

**输出模板**：`已拆解的产品域子决策（逐个归位）｜战略本体的纪律服务结论｜转介建议`。

**取数地图（常见数据去哪拿；政策行为 P2-A 新增）**：

| 数据 | 常见来源 | 口径提示 |
|---|---|---|
| 销量/动销/库存 | 内部 ERP/渠道周报 | 同店口径；动销率=动销 SKU 数÷在库 SKU 数 |
| 价盘/竞品价 | 渠道走访/电商比价/竞品周跟踪 | 成交价≠牌价；促销常态价单列 |
| 毛利/费比 | 财务月结 | 渠道费用与返利是否已扣（calc-pricing.py B5 扣减层） |
| 铺货率 | 渠道盘点/经销商进销存 | 铺货率=有货门店数÷目标门店数 |
| 政策/法规 | 监管部门官网/行业协会/合规方通报 | **政策行（P2-A）**：宣称边界/新规征求意见稿/品类标准变化——取数先查最新生效版本，不凭记忆引旧规；政策风险进约束卡 |

## 组件执行检查单

- [ ] 触发的是组件而非完整场景？（是→只提醒不决策）
- [ ] 风险提醒：6 维度逐维过，未命中维度标"未命中"
- [ ] 未知信息：引导后不补充→显式假设 ⚠️ 继续，不空等
- [ ] 生意三问：只体检不下结论
- [ ] 身份层（决策前提库固化）：L0 4 字段 + L1 4 字段已固化，或真缺失已按缺失清单处理（决策命中时显式「假设·未验证」/现场补问）
- [ ] 跨域拆解：对象枚举外时已走组件⑥（拆解优先+转介），未硬塞矩阵
- [ ] 复盘：AAR 四问+假设对照+决策质量/结果质量分开
- [ ] 输出格式逐条符合各组件格式
- [ ] 示例数据标"示例占位"
