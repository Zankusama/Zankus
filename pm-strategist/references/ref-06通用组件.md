# ref-06 通用组件（C类跨场景·五个组件）

> C类=用户问题不构成完整决策场景，只做组件级提醒：风险提醒/未知信息引导/生意思维三问/行业适配层/复盘。**只提醒不决策**，不给决策建议、不出 DR，除非用户接着给出完整决策问题（转对应场景）。
> 结构：五组件各含 触发时机/内容要点（标来源）/输出格式；末尾附组件执行检查单。

## 组件① 风险提醒

**触发时机**：每次给建议前过一遍；🔴不可逆决策必跑；涉及安全/合规的问题无条件先提醒、不等信息补齐。

**6 维度清单**（每维：典型风险点举例=示例占位 + 建议验证方式；只列风险点+建议验证，**不替用户做风险结论**）：

| 维度 | 典型风险点（示例占位） | 建议验证方式 |
|---|---|---|
| 法规 | 宣称用语超边界、备案/标识缺失、标签规范 | 查法规原文/合规方复核/小范围法务确认 |
| 市场 | 需求判断过时、季节波动、渠道需求变化 | 看近3周期销售数据/渠道访谈 |
| 竞争 | 竞品跟进降价、替代品截流、对手新品截胡 | 竞品价格带周跟踪/新品监测 |
| 供应链 | 断货、原料涨价、交期延误、库存积压 | 产能确认单/备货交期核对/库存水位 |
| 财务 | 毛利打穿、回本周期拉长、现金流承压 | 三情景测算/盈亏平衡复核（引 ref-04） |
| 组织 | 产线/人力排不过来、跨部门执行走形 | 资源排期确认/执行责任到人（RACI，引 fm-06） |

**输出模板**：`风险点（维度）｜影响程度（高/中/低）｜建议验证/规避动作` 逐条列；无风险的维度写"未命中"。

## 组件② 未知信息引导

**触发时机**：影响决策但用户没说的信息——先引导补充，不假设；引导后用户不补充→按**口径唯一化**处理：🔴不可逆决策停住不推演；🟢可逆决策标 ⚠️"假设·待验证"继续且输出顶部高亮假设清单；安全/合规无条件先提醒。不空等。

**通用维度**：决策目标（解决什么）、预算约束、时间窗、决策权（谁拍板）、数据可得性。

**各场景关键未知信息**（逐场景专列）：
- S1 新品立项：市场规模口径/目标人群画像/竞品对照/渠道适配/成本结构
- S2 组合规划：单品贡献度/增长趋势/产能约束/战略定位
- S3 生命周期：销售增速口径/获客成本/渗透率/利润趋势/复购
- S4 定价：价格带/成本与毛利目标/竞品价格/需求弹性
- S5 GTM：渠道结构/上市节奏/资源预算/物料准备

**输出模板**：`信息点 ｜ 为什么影响决策 ｜ 建议怎么获取` 逐条列；用户已给的信息不重复问。

## 组件③ 生意思维三问（通用化版）

**触发时机**：用户问"这生意值不值/该不该进/划不划算"，或任何决策前快速体检。

**三问展开**：
1. **赚不赚钱**（短期账）：商业模式（谁付钱为什么付）/收入结构（一次还是复购）/成本结构（大头在哪）/毛利水平（对比品类常态）/回本周期（多长、多确定）
2. **能不能持续**（中期账）：竞争壁垒（凭什么别人抢不走）/复购与留存（用完还买吗）/品牌力（主动指名吗）/供应链稳定性（断供风险）
3. **有没有壁垒**（长期账）：护城河类型（品牌/渠道/成本/技术/网络效应）/差异化（可感知吗）/复制难度（对手抄要多久花多少）

**输出模板**：三问各给 提问清单+现状判断句（判断必须标"不确定/待验证"若数据缺失）；三问只做体检提醒，**不出"该不该做"的结论**——那是场景决策（S1/S2）的事。

## 组件④ 行业适配层

**身份层 6 字段**：行业/品类/品牌阶段/组织分工/品牌定位/渠道结构。

**固化流程**：
1. 会话已载入（已读 `config/local_profile.md`）→ 跳过提问直接用
2. 初次使用 → 会话启动时提问固化 6 字段（**必填仅 2 个：行业大类+品类名称**；其余用到时现场确认），结果写入**包外**前提库：`--profile` 或环境变量 `PM_STRATEGIST_PROFILE`，默认 `~/.workbuddy/pm-strategist/profile.md`（跨机可移植，包内 config/ 只放空模板）；固化带【固化日期】确认戳，`python3 scripts/profile-check.py` 校验（闸口C：超期 90 天须重验）
3. 调用时信息（预算/时间窗/竞争动作/渠道现状）每次问每次用，**不写入**固化文件

**作用规则**：身份层字段与当前问题**强关联**（如渠道结构与铺货决策）→ 分析做透（A类标准）；**弱关联**（如组织分工与包装微调）→ 只提醒。判定由 PM 问题与字段的映射决定，输出中注明"本建议已按身份层校准"或"按通用快消语境·待行业校准"。

## 组件⑤ 复盘

**触发时机**：DR 到复盘日期/假设落空/用户要求复盘。

**内容要点**（详见 fm-04复盘框架.md）：
- **AAR 四问**：计划是什么/实际是什么/差异为什么/接下来怎么办
- **假设-结果对照**：DR 假设清单逐条标 应验/落空/待验，落空项写原因
- **决策质量 vs 结果质量**：好决策+坏运气≠错决策（评的是当时信息下的决策过程，不是只看结果）
- **经验沉淀**：把可复用的判断写成一句规则句，建议写进决策日志归档

**输出模板**：`复盘日期 ｜ AAR四问结论 ｜ 假设对照表 ｜ 经验句` + 原DR状态改为"复盘/关闭"。

## 组件⑥ 跨域拆解出口（品牌级战略本体）

**触发时机**：原语齐但对象枚举外——决策直接改动的是品牌本身（品牌重新定位/品牌架构重构等）。

**服务方式（拆解优先）**：
1. 按 100% 规则拆出产品域可执行部分，逐个归位拿弹药（如"品牌年轻化"→拆出 目标人群/产品迭代/价格带 等子决策，各自走矩阵）
2. 战略本体部分 → **纪律服务**：显式假设+最强反方+风险六维（品牌重新定位=🔴不可逆）+ DR9 收尾
3. 显式声明："品牌战略本体超出场景弹药——本 skill 是产品决策军师，不是品牌战略顾问"
4. 转介锚点：Aaker 品牌谱系（品牌资产模型/品牌架构四型）；架构落回产品域的部分（挂主品牌还是子品牌）走 ref-01 品牌架构适配项（层2 定义属性）

**输出模板**：`已拆解的产品域子决策（逐个归位）｜战略本体的纪律服务结论｜转介建议`。

**取数地图（常见数据去哪拿；政策行为 P2-A 新增）**：

| 数据 | 常见来源 | 口径提示 |
|---|---|---|
| 销量/动销/库存 | 内部 ERP/渠道周报 | 同店口径；动销率=动销 SKU 数÷在库 SKU 数 |
| 价盘/竞品价 | 渠道走访/电商比价/竞品周跟踪 | 成交价≠牌价；促销常态价单列 |
| 毛利/费比 | 财务月结 | 渠道费用与返利是否已扣（calc-pricing.py B5 扣减层） |
| 铺货率 | 渠道盘点/经销商进销存 | 铺货率=有货门店数÷目标门店数 |
| 政策/法规 | 监管部门官网/行业协会/合规方通报 | **政策行（P2-A）**：宣称边界/新规征求意见稿/品类标准变化——取数先查最新生效版本，不凭记忆引旧规；政策风险进约束卡 |

## 组件执行检查单

- [ ] 触发的是组件而非完整场景？（是→只提醒不决策）
- [ ] 风险提醒：6 维度逐维过，未命中维度标"未命中"
- [ ] 未知信息：引导后不补充→显式假设 ⚠️ 继续，不空等
- [ ] 生意三问：只体检不下结论
- [ ] 行业适配：身份层 6 字段已固化（闸口C 通过）或已按假设校准
- [ ] 跨域拆解：对象枚举外时已走组件⑥（拆解优先+转介），未硬塞矩阵
- [ ] 复盘：AAR 四问+假设对照+决策质量/结果质量分开
- [ ] 输出格式逐条符合各组件格式
- [ ] 示例数据标"示例占位"
