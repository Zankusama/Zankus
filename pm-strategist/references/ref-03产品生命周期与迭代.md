# ref-03 产品生命周期与迭代（场景S3·A类）

> 场景：这个品卖不动了怎么办/成熟品怎么迭代/现在处于生命周期哪个阶段。A类=PM职责内完整决策，分析透。
> 结构：一、检查单 → 二、框架要点（PLC四阶段+按阶段补充+跨阶段）→ 三、输出模板。

## 一、检查单 · 生命周期判断与迭代

> **核心项=PM必做**；**协作项=PM提供输入**。

### 阶段判断（五维度，先判阶段再谈动作）
- [ ] 【核心】销售增速档位（连续≥3个周期：加速/放缓/持平/下滑）
- [ ] 【核心】获客成本趋势（新客/新店获取变贵还是变便宜）
- [ ] 【核心】市场渗透率估计（品类渗透到什么位置，天花板还有多远）
- [ ] 【核心】竞争格局变化（进入者变多/价格战/替代品出现）
- [ ] 【核心】利润趋势（毛利稳定/被促销侵蚀/结构性下滑）
- [ ] 【协作】渠道库存水位（渠道压货情况，销售输入）
- [ ] 【协作】竞品动态情报（市场输入）

### 迭代决策（判完阶段后逐条过）
- [ ] 【核心】迭代目标一句话（续命/提利润/防守份额/升级形象，只能主选一个）
- [ ] 【核心】迭代范围界定（配方/包装/规格/价格带/宣称——动哪几层）
- [ ] 【核心】可逆性判定（🟢包装微调可逆 / 🔴整体换配方、重新定位不可逆）
- [ ] 【核心】老品衔接计划（老库存消化/渠道切换节奏）
- [ ] 【核心】假设清单显式化（⚠️"假设·待验证"逐条：新包装拉动复购/提价不流失等）
- [ ] 【协作】试制品验证结果（研发输入）
- [ ] 【协作】成本变化核算（供应链输入）

### 复盘机制（每次迭代后触发）
- [ ] 【核心】AAR 四问已跑（计划/实际/差异原因/下一步，见 fm-04）
- [ ] 【核心】假设-结果对照（开工时 ⚠️ 清单逐条应验/落空）
- [ ] 【核心】决策质量 vs 结果质量分开评（好决策坏运气≠错决策）
- [ ] 【核心】经验沉淀条目（写进下次决策可引用的规则句）

## 二、框架要点

### PLC 四阶段判断（来源：经典产品生命周期理论，判据维度见检查单）
| 阶段 | 销售增速 | 获客成本 | 渗透率 | 竞争格局 | 利润趋势 |
|---|---|---|---|---|---|
| 引入期 | 低/波动 | 高 | 极低 | 少 | 负或微利 |
| 成长期 | 快速上升 | 下降中 | 快速爬升 | 进入者增多 | 改善并放大 |
| 成熟期 | 放缓/持平 | 变贵 | 高位 | 价格战/存量博弈 | 被促销侵蚀 |
| 衰退期 | 持续下滑 | 高且无效 | 被替代品替代 | 退出者增多 | 结构性下滑 |

### 按阶段补充框架
1. **引入期——跨越鸿沟 + 罗杰斯扩散**（来源：Geoffrey Moore《跨越鸿沟》；Everett Rogers 创新扩散）。要点：创新者/早期采用者与主流大众之间有鸿沟，"早期卖爆"≠"大众会买"；引入期目标是从尝鲜人群向早期大众找可复制打法，不急于全渠道铺开。
2. **引入期——精益创业**（来源：Eric Ries）。要点：用 MVP 思路小市场试销，验证"最致命假设"再放量。
3. **成长期——HBG**（来源：Byron Sharp《How Brands Grow》）。要点：增长主要靠渗透率（更多买家）而非加深忠诚；物理可得性（铺货/货架）优先，心智显著性（一眼想到你）其次。
4. **成长期——4P 扩张**（来源：McCarthy 4P）。要点：渠道从核心渠道向邻接渠道复制、规格/口味按场景延展、促销从教育转向比较优势。
5. **成熟期——产品三层次**（来源：Philip Kotler 产品层次理论：核心利益/有形产品/附加产品）。要点：成熟期同质化从有形层开始，迭代优先在附加层（服务/组合/场景）找差异，避免单纯价格战。
6. **成熟期——KANO 焕新**（来源：狩野纪昭）。要点：上一代的兴奋需求已被视为基本需求；用 KANO 重测需求结构找新兴奋点（配套 `scripts/kano-classify.py`）；成本优化并行（配方/包材降本不降认知价值）。
7. **衰退期——终结管理 + 三层面资源转移**（来源：产品终结管理实践；McKinsey 三层面）。要点：衰退品先判断"品类衰退还是品牌衰退"——品类衰退考虑有序退出，品牌衰退考虑焕新；退出计划含库存消化/渠道衔接/用户迁移；资源（货架/预算/产线）按三层面转移给 H2/H3。

### 跨阶段框架
- **AAR 四问**（来源：美军事后回顾方法 AAR）：计划是什么/实际是什么/差异为什么/接下来怎么办——每次迭代必跑（详见 fm-04复盘框架.md）。
- **假设-结果对照**：迭代立项时的 ⚠️ 假设清单逐条对照结果，落空项写原因——这是把"迭代"变成"学习"的关键动作。
- **4P 动态调整**：阶段切换时四要素的重心会移（引入期重 Product 认知→成长期重 Place 铺货→成熟期重 Price 促销效率→衰退期收缩）。

## 三、输出模板

### S3 决策建议模板（建议6要素）
```
【场景】S3 产品生命周期与迭代 ｜ 可逆性=🟢/🔴/🟡[|⚠️高风险] ｜ 主查=ref-03+fm-04
1. 选项（≥2，含不做/维持现状）：示例占位——包装焕新+规格延展 / 维持现状只做促销效率 / 有序退出转资源给新品
2. 推荐倾向：明确倾向+阶段判断依据（五维度数据）
3. 权衡分析：各选项对 增速/毛利/渠道/品牌 的影响对账
4. 不做项说明：明确不动什么（如：不动核心配方——宣称作废风险）
5. 风险（6维度命中项）：列风险点+验证方式
6. 数据需求引导：增速精确数/渗透率口径/复购数据
```

### S3 决策记录模板（DR9字段，收敛终端）
```
# DR-YYYYMMDD-<slug>
- 问题：[示例占位：A品连续两季下滑，迭代还是退出]（场景S3｜决策者=用户｜截止=YYYY-MM-DD）
- 选项：焕新迭代 / 维持现状 / 有序退出
- 决定：用户拍板原文或推荐倾向
- 依据：ref-03五维度判断（阶段=成熟期）+选用的阶段框架条目
- 反方意见：最强反方+什么数据会推翻（如：下滑主因是渠道断货而非产品老化）
- 风险：6维度风险点+验证方式
- 假设清单：⚠️ 前缀"假设·待验证"逐条列
- 复盘日期：YYYY-MM-DD（建议=迭代上线后 1-2 个销售周期）
- 状态：草案/已定/复盘/关闭
```

---
适用时机：阶段判断、迭代立项、迭代复盘。已知局限：五维度数据口径不一致时阶段判断易错——先统一口径再判阶段；阶段边界是渐变的，贴标签为了选工具不为定论。检查单保证完整性，不保证正确性。
