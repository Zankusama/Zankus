# ref-02 产品线组合规划（场景S2·A类）

> 场景：SKU 太多怎么取舍/产品线要不要砍或加/资源往哪个品倾斜。A类=PM职责内完整决策，分析透。
> 结构：一、检查单 → 二、框架要点（NPDP标准结构+5补充+RICE/WSJF用法）→ 三、输出模板。

## 一、检查单 · 产品线组合规划

> **核心项=PM必做**（缺任一项=检查不过）；**协作项=PM提供输入**。

### 组合选择（决定哪些品进/留/出组合）
- [ ] 【核心】单品贡献度账本（每 SKU：销售额/毛利额/占比，数据源注明）
- [ ] 【核心】增长趋势分档（每 SKU 近 3-4 个周期销量/销售额增速）
- [ ] 【核心】战略定位标注（每 SKU：引流/利润/形象/试销角色）
- [ ] 【核心】产能与资源约束清单（能养几个品的真实上限）
- [ ] 【核心】候选动作清单（新进/保留/收缩/淘汰，每 SKU 一个动作）
- [ ] 【协作】财务毛利口径校准（财务提供）
- [ ] 【协作】产能/交期约束确认（供应链提供）
- [ ] 【协作】渠道适配约束（渠道结构现状，销售输入）

### 组合评审（定期回头看，组合健康度）
- [ ] 【核心】五目标打分：价值最大/项目平衡/战略一致/管道平衡/盈利充分（逐条过）
- [ ] 【核心】平衡度检查：高低毛利搭配/长短期搭配/风险高低搭配
- [ ] 【核心】淘汰品退出计划（库存消化/渠道衔接/时间表）
- [ ] 【核心】评审节奏已定（季度/半年度，日期入 DR 复盘字段）
- [ ] 【协作】管理层对组合方向的确认输入
- [ ] 【协作】渠道反馈回流（渠道不要什么、缺什么）

## 二、框架要点

### NPDP 标准结构（来源：PDMA NPDP 知识体系）
- **五目标**：①价值最大（组合总商业价值）②项目平衡（风险/长短/品类）③战略一致（组合服从战略）④管道平衡（在途项目数量与资源匹配）⑤盈利充分（财务目标达成）
- **两活动**：组合选择（进什么/留什么/出什么）+ 组合评审（定期健康度回看）
- **选择方法三级**：通过失败法（简单门槛筛）→ 评分法（多准则加权打分）→ 财务分析（NPV/回本测算）——小组合从二级起步即可

### 5 个补充框架（每个标互补环节）
1. **三层面增长 H1/H2/H3**（来源：McKinsey《增长炼金术》）——互补"平衡"目标。H1=当前核心品（守）、H2=新兴品（攻）、H3=未来选项（试）；组合三层都有位置才算健康，全压 H1=透支未来。
2. **波士顿矩阵 + GE 矩阵**（来源：BCG 波士顿咨询；GE-McKinsey 九宫格）——互补组合选择。BCG 按市场增长×相对份额分四象限（明星/现金牛/问题/瘦狗）；GE 九宫格用"市场吸引力×竞争实力"更细。要点：矩阵是讨论工具不是判决书，落哪个格子要用数据说话。
3. **Ansoff 矩阵**（来源：Igor Ansoff）——互补新进品方向。现有品×现有市场（渗透）/现有品×新市场（开发）/新品×现有市场（延伸）/新品×新市场（多元）；风险从左到右递增，快消新品多走"延伸"格。
4. **Stage-Gate 关口动态治理**（来源：Robert Cooper Stage-Gate）——互补组合评审。组合不是一次定终身：新机会过闸进、在售品定期评审出；关口决策四分类=通过/否决/搁置/重做。
5. **敏捷精益组合**（来源：精益创业实践融入组合管理）——互补 H3 层。不确定性高的候选用小预算试销验证（MVP 思路），验证过闸再升级为正式组合项目；避免"要么全投、要么不投"的两极决策。

### RICE / WSJF 用法（配套脚本 `scripts/priority-calc.py`）
- **RICE** = (Reach×Impact×Confidence)÷Effort：Reach=覆盖用户/渠道数（人/店数）、Impact=单点影响（高3/中2/低1/最低0.5）、Confidence=把握（1/0.8/0.5）、Effort=投入（人·月）。适用：多 SKU 抢同一批资源时的通用排序。
- **WSJF** = (用户商业价值+时间关键性+风险降低或机会启用)÷工作量：适用：窗口期明显（季节品/节点品）、延误代价大时的排序。
- 用法纪律：打分口径先统一（数字含义写进 DR 依据），出分后用组合五目标复核（战略一致性违反任一，排序不直接采纳）；示例数字一律标"示例占位"。

### 衍生规格引入检查（增×现有单品 → S2★，矩阵补全格）

衍生规格（礼盒/限定/季节款等变体）进组合前：
- [ ] 动机消歧（F3）：价格点管理动机 → 归 S4 规格价格架构；变体丰富动机 → 本场景；动机不明 → 闸口 A 透出双候选，用户定
- [ ] 品牌-SKU 映射：新规格挂哪个品牌/子品牌？（映射关系入 DR 依据；架构选型见 ref-01 品牌架构适配项）
- [ ] 自我蚕食估计：新规格对母品销量的替代比例与可接受度
- [ ] 渠道/库存联动：新规格对母品铺货与库存水位的影响（引约束维度节）

## 跨职能约束维度（决策点检查；B 类从"输出后标注"升级为**输入前检查**）

> 用法：每到一个决策点，先扫 7 维（≤4 条入约束卡）；每维回答"PM 要回答什么+谁拍板"。
> 品牌资产=第 7 维（总案 D5 层1：品牌作为产品决策的受影响维度，如"降价伤不伤调性"在此检查）。

| 维度 | PM 要回答什么 | 谁拍板（B 类标注） |
|---|---|---|
| 法规合规 | 宣称/备案/标签边界在哪？ | 法务/合规 |
| 渠道适配 | 各渠道接不接、要什么条件？ | 销售/渠道 |
| 促销空间 | 促销价盘与费比空间多少？ | 销售+财务 |
| 库存动销 | 备货/清仓水位与动销口径？ | 供应链 |
| 成本 | 完全成本与量产达成？ | 财务/供应链 |
| 财务 | 毛利口径与回本口径？ | 财务 |
| **品牌资产（第7维）** | 此动作对品牌资产/调性/价格形象的影响？ | 品牌部/CMO |

## 三、输出模板

### S2 台面模板（四区；[完整]/[轻]/[快轨] 徽章路由，机器校验 check_output.py）
```
[完整] ｜ S2 产品线取舍（示例占位）
（开场人话：这是砍产品线级的决定，退不回——我先跟你确认<X>）
【建议】<明确推荐，一句话（引用 RICE/WSJF 排序或五目标复核结论作依据）>（置信度：高/中高/中 · 一句依据）
下一步（你）：<第一动作（如：确认单品贡献度是否已扣渠道返利）>
【为什么】
1. <可验证事实/数字 → 所以…>（如：贡献度连续下滑 → 所以资源机会成本在主力线）
2. <论据>（完整态 ≥2 条）
【为什么不选别的】
- 逐季自然收缩：死于库存与渠道关系拖尾成本高于一次性处置（示例占位）
- 维持现状：代价是每月倒贴仓储与陈列，下滑未见底
【换挡条件】若<信号+阈值，如某"瘦狗"品实为渠道入场券（合约条码门槛）> → 结论改为<选项>；复盘日 <YYYY-MM-DD>
【最可能翻车的点】<最强反方（具体条件+可反驳出口）>——不同意就怼，我当场对
（档案已存：./决策记录/DR-YYYYMMDD-xxx.html——9 字段/风险六维/假设/反方/探讨轨迹齐全）
```

### S2 决策档案模板（9字段+探讨轨迹+归位，收敛后落盘）
```
# DR-YYYYMMDD-<slug>
- 问题：[示例占位：三条子产品线资源有限，下季度怎么取舍]（场景S2｜决策者=用户｜截止=YYYY-MM-DD）
- 选项：收缩双主力 / 维持现状 / 自然收缩
- 决定：用户拍板原文或推荐倾向
- 依据：ref-02五目标复核+RICE排序表（示例占位）+fm-03条目
- 反方意见：最强反方+什么数据会推翻（如：某"瘦狗"品实为渠道入场券）
- 风险：6维度风险点+验证方式
- 假设清单：⚠️ 前缀"假设·待验证"逐条列
- 复盘日期：YYYY-MM-DD（建议=下次组合评审日）
- 状态：草案/已定/复盘/关闭
- 探讨轨迹：初步版→用户反驳（引用用户原话）→结论如何更新；或 用户跳过探讨：原因=X+证据
- 归位：删×产品组合 → S2 ｜ 归位成功 ｜ 理由一句话 ｜ 可逆性=🔴/🟢（只读段，收敛闸校验）
```

---
适用时机：季度/年度组合评审、SKU 争议、资源倾斜决策。已知局限：贡献度数据滞后于市场变化，"该砍的品恰在拐点前"是本场景最常见误判——淘汰动作尽量给缓冲期；检查单保证完整性，不保证正确性。
