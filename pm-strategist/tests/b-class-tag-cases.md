# b-class-tag-cases.md — B类跨部门标注用例

> B类场景（S4 定价 / S5 GTM）输出边界断言：PM 职责内做透分析 + 必附跨部门确认标注。

| # | 输入 | 期望行为 | 断言 |
|:--:|:---|:---|:---|
| BT1 | "这个品定多少价？"（S4） | 分析做透（流程8步/5框架/测算），输出含标注 | 文本含逐字标注：「最终定价决策需跨部门确认（财务/销售/渠道/管理层）」 |
| BT2 | "新品怎么上市、先铺哪些渠道？"（S5） | 策略/计划/就绪/跟踪做透，输出含标注 | 文本含逐字标注：「最终上市决策需跨部门确认（销售/市场/供应链/管理层）」 |
| BT3 | S4/S5 输出收尾 | DR 状态可标"草案"，不替管理层拍板 | 无"已定（价格=X）"类最终拍板结论；标注紧跟 DR 或建议末尾 |

## 机器校验

- `python3 scripts/check_output.py <输出>`：场景=S4/S5 时缺对应标注 → 报"B类场景缺跨部门确认标注"退出 1（实测见验收记录）
- grep 逐字校验：`grep -c "需跨部门确认" ref-04定价与盈利.md` ≥1、ref-05 ≥1（基线实测各 4 处）
