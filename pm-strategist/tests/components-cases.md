# components-cases.md — C类组件用例

> ref-06 通用组件 6 项的可走查行为契约子集：风险提醒 / 未知信息引导 / 生意思维三问 / 身份层（决策前提库固化） / 复盘 / 跨域拆解出口。

| # | 输入情境 | 期望行为 | 断言 |
|:--:|:---|:---|:---|
| C1 | "帮我看看这个决策有什么风险" | C类触发：风险 6 维度提醒（法规/市场/竞争/供应链/财务/组织），只列风险点+验证方式 | risk-check.py 全覆盖样本退出 0、缺维样本退出 1；不出现风险结论句（"所以不能做"=违规） |
| C2 | 用户只说"要不要进这个生意"（无细节） | C类：生意思维三问体检+未知信息引导，不结论 | 输出含 赚不赚钱/能不能持续/有没有壁垒 三问结构；无"该不该做"结论句 |
| C3 | 初次会话直接问场景决策 | 身份层（决策前提库固化）：先固化身份层 8 字段位（L0 4：行业/品类/目标客群/公司规模；L1 4：品牌阶段/渠道结构/拍板权/定位禁区；必填仅 行业大类+品类名称，其余宽松），走回显确认固定步骤（**v4.3 起载入即回显**：profile-check 打印全文 → 逐条确认 → 打戳落盘；首采全量回显），用户不答→显式假设 ⚠️ 继续；**问句走白话脚手架（现象问法，禁裸甩字段名）**；profile-check 双闸门（闸A 缺模板字段/闸B 版本落后 → exit 1 拦，升级走迁移回显）+ 真缺失（键在值空）列缺失清单 warn **不拦流程** | 身份层字段名逐一出现（行业/品类/目标客群/公司规模/品牌阶段/渠道结构/拍板权/定位禁区）；回显确认步骤出现（载入/首采回显 → 逐条确认/纠正 → 打戳）；缺字段标注"假设·待验证"且流程不被拦死；采集问句为白话现象问法（无"L0/L1/首采门槛"黑话裸问）；升级后旧 schema（缺新键/版本落后）须被 profile-check exit 1 拦下 |
| C4 | "上次那个决策复盘一下" | C类：AAR 四问+假设-结果对照+决策质量 vs 结果质量 | 输出含四问结构与对照表；DR 状态推进为 复盘/关闭 |

## 断言（通用）

- C类只提醒不决策：不给决策建议、不出 DR（除非用户接着给出完整决策问题转对应场景）
- 未知信息引导后用户不补充 → 显式假设 ⚠️"假设·待验证"继续，不空等；安全/合规风险无论如何先提醒
