|:--:|:---|:---|
| P1 | 新品评估：我们要不要上一条新产品线？ | 触发，启动类路由 + 判可逆性 |

## 断言

- description 触发词（新品评估/产品决策/帮我决策/该不该做/值不值得做/优先做哪个/怎么做取舍）命中以上任一 → 应触发
- 触发后第一条回复必声明执行路径（可逆轻流程 / 不可逆全流程）
- 触发后先问用户自己的判断（路由轨先问"你先说判断，我再给建议"，见 SKILL.md 双轨分流）
