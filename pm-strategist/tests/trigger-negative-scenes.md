# trigger-negative-scenes.md — 反向用例（不误触发/不误路由）

> 无关问题→不应作为 5 场景决策触发；应路由或按 C类组件处理。

| # | 用户输入 | 期望行为 |
|:--:|:---|:---|
| TN1 | 分析一下为什么这个品卖不动（根因归因） | 不触发决策场景——属"为什么"层归因，不在本技能范围 |
| TN2 | 帮我把这个需求写个任务书 | 不触发——属需求澄清/任务书撰写，不在本技能范围 |
| TN3 | 你好 / 今天天气不错 | 不触发——纯闲聊 |
| TN4 | 把这段文案错别字改了 | 不触发——纯文件操作，无决策属性 |
| TN5 | 我们这个生意值不值？（无具体决策问题） | 不进 A/B 场景——C类组件（生意思维三问）只提醒不决策 |

## 断言

- TN1/TN2 不触发决策场景（归因/任务书不属本技能范围），不出决策建议
- TN3/TN4 直接干活或闲聊，不产 DR
- TN5 走 ref-06 生意思维三问：只体检、不下"该不该做"结论
- scene-router 对 TN5 类输入返回 `场景=C类` 且类别=C（低置信度时不硬塞 A/B 场景）
