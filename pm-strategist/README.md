# pm-strategist · 产品军师

帮 PM 在真实业务场景下做决策：判可逆性 → 决策原语路由（动作×对象 → 25 格矩阵归位，闸口 A 确认）→ 双轨分流（用户先说判断）→ 五场景装弹药 → 涉算账必调 calc-pricing.py（含渠道费用与返利扣减层）→ 探讨收敛（初步版→反驳→无新意熔断）→ 落盘 HTML 决策档案（v0.7 暗黑横版/浅色双主题；9 字段+探讨轨迹+归位）。决策是目的，方法论只是弹药。

> **测试版声明**：v4.4.1 为体验层改造版（v4.4.1=盲审三缺口修复）（台面四区契约 + 探讨轮 + 收敛闸 + 决策档案信息图化；四轮对抗评审 + 自动化测试协议 + 康复治疗）；机制经过 golden/四态/台面 T1-T9/收敛闸/算账护栏回归，真人反馈样本仍少——使用中请按文末反馈模板回话。

## 覆盖边界披露（先读再用）

- **擅长**：快消 PM 的产品决策——新品立项/组合取舍/生命周期迭代/定价盈利/上市 GTM；风险与反方结构化；决策留痕复盘。
- **不擅长**：品牌战略本体（走跨域拆解出口+Aaker 谱系转介）、深度财务建模、组织人事决策、执行类文案。
- **C 类边界**：不构成完整决策的问题只做组件级提醒（只提醒不决策）。
- **台面形态**：给用户看的输出=四区固定格式（徽章 [完整]/[轻]/[快轨] 按可逆性路由，机器校验 check_output.py）；框架名与 ref/fm 编号不上台面，论证必须上台面；台面禁裸百分比（置信度只用三档词）。DR 档案校验唯一入口=decision-record.py（收敛闸：探讨轨迹缺段 exit 1）。
- **质量下限 ≠ 判断力**：闸口与质量下限校验（选项含不做/反方可证伪/风险不空转/依据有出处/已定须拍板原文/探讨轨迹在场）只保证**下限**；判断力的胜负手在用户自带的业务判断——本 skill 不夸大这一条。

## 安装

本 skill 是**一个纯本地目录**（含 SKILL.md 的那个），装到目标客户端的 skills/ 目录即可——软链接或复制二选一。零第三方依赖、零联网，对客户端无特殊要求。

**软链接**（改本目录即时生效，多处共用一份；⚠️ 删客户端目录前先删软链接，否则会连带删源）：

```bash
SKILL_DIR="$(pwd)"   # 假设当前已在包含 SKILL.md 的本 skill 根目录
ln -s "$SKILL_DIR" "<你的客户端 skills 目录>/pm-strategist"
```

**复制**（各客户端独立，改动不回流，最稳妥）：

```bash
cp -R "$(pwd)" "<你的客户端 skills 目录>/pm-strategist"
```

常见客户端 skills 目录（按需取用其一即可，不必全装；以你所用客户端的文档/实际路径为准）：

| 客户端 | skills 目录（默认） |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/` |
| Trae | `~/.trae-cn/skills/` |
| Qoder | `~/.qoder/skills/` |
| QwenWork | `~/.qwenworkcn/skills/` |
| QoderWork | `~/.qoderworkcn/skills/` |
| AutoClaw | `~/.openclaw-autoclaw/skills/` |

> 多客户端共用一份源码时，用软链接方式安装（见上），各客户端改动即时同源；想批量挂载可自行写一个软链接脚本。

> ⚠️ 身份层 = **skill 目录内 `config/local_profile.md`**（唯一文件：收到即空模板、填了即本机档案；相对路径，任何部署通用，零外部依赖/多端环境；`--profile` 或环境变量 `PM_STRATEGIST_PROFILE` 可覆盖）。填写版含个人数据**勿提交/勿随包分享**（分享前 pre-publish-check 自检 FAIL 提醒）。DR 落盘默认 `./决策记录/`（运行时产物，分享前清空），偏好存 `config/pm_settings.json`。
>
> **记忆分层**：L-长期（profile 身份层：L0 4 字段 + L1 4 字段 + 经验句区，跨会话、回显确认后落盘）＋ L-情境（四变量，随 DR 草案承载、决策关闭即过期）——两层之间只有一条升级通道（情境表述跨 ≥2 次决策仍成立 → 必问"记入长期前提吗？"→ 判据归位）。归层判据见 SKILL.md「身份层」。

> **分享给他人（接收者视角）**：包内零个人数据、克隆即用——身份层 `config/local_profile.md` 收到时是空模板，首次使用走首采（约 8 个白话问题建档），未填字段标 ⚠️ 假设·待验证、不拦决策流程；**单机可用、无需任何外部系统或平台配置**——你的档案就存在这个 skill 目录里，随包走、不污染别处。接收者无需为"用"维护任何东西；只在作者发布新版本时 pull 更新（升级后若 profile-check exit 1，走迁移回显一次即可）。

## 使用

对它说：新品评估 / 产品决策 / 帮我决策 / 该不该做 / 怎么取舍 / 值不值得做 / 优先做哪个 / 定价 / 涨价 / 促销 / 大促 / 上市 / 渠道 / 经销商 / 库存 / 清仓 / 临期 / 窜货 / 进场费 / 品牌重新定位 / 品牌架构 / 复盘 / 生意三问……（完整触发词见 SKILL.md description）。半成形表达也接："我有个想法你帮我看看"。
NOT for：「为什么/根因」类归因分析、需求澄清与任务书撰写、纯闲聊、纯代码编辑。

## 测试与验收

> 以下命令在 **skill 目录内**执行（测试脚本会自行定位 skill 根目录）；在外部目录跑脚本类命令须带 `"$SKILL_DIR/"` 前缀——先赋值 `SKILL_DIR=<本 skill 安装路径>`，见 SKILL.md「脚本调用路径约定」。

```bash
bash tests/run_tests.sh                  # 结构+触发+红线+golden+四态+台面T1-T9+收敛闸+算账护栏（退出码 0=全绿）
bash tests/test-scripts.sh               # 10 脚本功能测试
python3 scripts/scene-router.py --self   # 路由器自检（golden G1-G5+四态12例）
python3 scripts/calc-pricing.py --self   # 算账器自检（B5 渠道扣减层+护栏3条）
python3 scripts/profile-check.py --self  # 闸口C 自检（确认戳+90天重验）
python3 scripts/decision-record.py --self # DR 自检（收敛闸+探讨轨迹/归位+v0.7双主题+回退开关）
python3 scripts/check_output.py --self   # 台面四区 T1-T9 断言组（full/light 双模式）
```
