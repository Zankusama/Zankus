# 产品军师 · 快消 PM 的决策助手

一个帮你在**真实业务里把产品决策做对**的工具：你把要定的事告诉它，它帮你摆清选项、算清账、把可能的坑和反方意见摆上台面，最后留一份能回看的决策档案。**它是参谋，不是替你拍板的人。**

## 这是什么（一句话）

把"要不要做 / 砍哪个 / 定多少价 / 先铺哪 / 怎么迭代"这类产品决策，从头帮你理一遍：先判断这事退不退得回，再给选项和依据、主动抬杠挑毛病、帮你想清楚"做到什么程度叫成功、什么信号说明该掉头"，最后落在纸上供复盘。**每个结论都带上依据和反方，不给裸结论。**

## 一次完整的体验长什么样（30 秒 mini 示例）

假设你纠结"要不要给 A 品出个小规格（比如 9.9 元三连包）"：

1. 你一句话问它："想出个 9.9 元三连包，要不要做？"
2. 它先判断：这属于**定价/规格**类决策，回不回得了头（大概率能，小流量试）——它用大白话跟你说"这事先当轻量决策处理"。
3. 它问你一两句关键的：目标客群是谁、有没有渠道 / 复购数据，缺的数它标成"假设，等你验证"，不逼你瞎填。
4. 它给结论：**建议怎么做 + 为什么 + 没选其他方案的原因 + 做到什么程度算失败（掉头信号）+ 它最可能翻车的点**——全部带依据，你不用盲信。
5. 你不同意，可以当场怼，它会把你的反对写进"探讨轨迹"并改判或守住。
6. 最后它生成一份自包含的决策档案（HTML），点开就能复盘：当时定了什么、凭什么、风险有哪些、当初的假设后来应验没有。

全程**不丢上下文、不逼你按黑话说话、每一步都留痕**。

## 什么时候用 / 什么时候别用

**用它做**：新品立项与迭代、产品线取舍 / 砍品、定价与调价、促销费效、渠道上市 / 铺货、库存清仓、品牌小步调整——以及"我有个想法你帮我看看"这类半成形的诉求。

**别用它做**（它只提醒、不越界）：纯"为什么卖不动"的根因归因、需要你写需求文档或执行文案的活儿、纯闲聊、代码编辑。品牌级大方向（如"要不要重新定位品牌"）它会明确告诉你"这超出产品决策弹药，并把你能执行的产品部分拆出来帮你做"。

> 它说的话里如果有你不懂的行业词（毛利/返利/铺货率/进场费/复购…）——**不懂的术语都会解释**：直接问，它会用大白话解释，不会拿术语把你挡在门外。

## 边界与承诺

- **擅长**：快消 PM 的产品决策——立项 / 组合取舍 / 迭代 / 定价盈利 / 上市 GTM；把风险、反方和"什么算失败"结构化；决策留痕，方便复盘。
- **不擅长（如实说）**：品牌战略本体、深度财务建模、组织人事决策、执行类文案。
- **质量下限 ≠ 判断力**：它保证的是"选项摆齐、反方能证伪、风险不空转、依据有出处"这些**下限**；到底选哪个，判断力在你手里——它不吹"跟它做就稳赢"。
- **置信度只说档位不说假精确**：它给你"高/中/低"档，不会假装算到一个精确百分比。

## 安装

本 skill 是一个**纯本地目录**（含 SKILL.md 的那个），装到目标客户端的 skills/ 目录即可——软链接或复制二选一。零第三方依赖、零联网。

**软链接**（改本目录即时生效，多处共用一份；删客户端目录前先删软链接，否则会连带删源）：

```bash
SKILL_DIR="$(pwd)"   # 假设当前已在包含 SKILL.md 的本 skill 根目录
ln -s "$SKILL_DIR" "<你的客户端 skills 目录>/pm-strategist"
```

**复制**（各客户端独立，改动不回流，最稳妥）：

```bash
cp -R "$(pwd)" "<你的客户端 skills 目录>/pm-strategist"
```

常见客户端 skills 目录（按需取用其一即可，以你所用客户端的文档/实际路径为准）：

## 第一次用它，先填一份"你的背景"（可选但推荐）

你所在的行业 / 品类 / 客群 / 公司规模、品牌阶段、渠道结构、谁拍板、哪些是红线——填得越清楚，它给的结论越贴合你的处境。**整个流程用大白话问，8 个现象级问题，填不全也没关系**，缺的会标注为"假设"，不阻塞你用。这份背景存在本 skill 目录的 `config/local_profile.md` 里，跟包走、不污染别处。

## 用完，怎么回看你做过的决策

每次收敛后的决策会存成一份自包含 HTML 档案（默认落在当前目录的 `决策记录/` 下）。复盘时读档案即可：当时定了什么、依据、反方、风险、假设、复盘日期——一条不少。

## 发布与隐私（重要，分享前必读）

- 本目录里的 `config/local_profile.md` 默认是一份**空模板**（占位符），里面存的是**你个人的业务背景**，填了就是本机专属档案。
- **这份档案含你的信息，请勿随包提交到公共仓库 / 分享给他人**。要发版本时在 skill 目录内跑一次发布流程 `bash scripts/publish-check.sh`（自动备份→净化→跑 `pre-publish-check.sh` 全 PASS→给出上传清单→恢复你的本机档案）；它也拦**整目录上传**这条最容易泄密的路（全程不会把 `config/local_profile.md` 的填写版留在任意一份发出版里）。
- `决策记录/` 下的档案是运行时产物，分享打包前建议清空。
- 包内其余内容零个人数据、零第三方依赖、零联网，克隆即用。

纯 Markdown + Python 标准库（json/argparse/datetime/re），零第三方依赖、零网络请求。

## 设计文档（写给想了解"它怎么工作"的人；用的时候不用读）

调用约定 / 机制黑话 / 脚本清单 / 判定口径说明，移步 `SKILL.md`「闸口总表」与「脚本清单」节。一句话版：它把每个产品决策抽象成"要做什么动作（新做/砍/改/选一个/只评估）× 对着什么东西（新品/组合/现有品/价格/渠道）"，落到对应的 25 个格子之一，再按可逆性分级、装弹药、算账、探讨、落盘。**这部分是为懂机制的人看的调试说明，不影响你日常使用。**
