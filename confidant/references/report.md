# 情绪画像输出规范（report）

> 情绪画像是 confidant 的**强制产出物**：达根因即出，对方确认说完了未达根因则出「进展小结」。
> 格式统一为 **HTML 单页信息图**（`references/report_template.html`，自包含 + 内联 SVG），经 `present_files` 展示给用户。
> 本文件管「何时出 / 怎么填模板 / 结构铁律 / 分级深度 / 接收度 / 画像后闭环 / 去医感与免责硬要求」，模板本体在 `report_template.html`。

## 一、何时生成（强制，非用户主动才出）

| 情形 | 动作 |
|:---|:---|
| 聊到根因（下方三条自检全过） | 立即按 `report_template.html` 生成 HTML 信息图，present_files 展示 |
| 对方确认说完了（Gate1 过）+ 三条自检全过 | 立即按选定模板（`check_readiness.py` 判定 conceptual / narrative）生成 HTML 信息图，present_files 展示 |
| 纯危机（命中危机信号） | 走 `crisis.md` 转介流程，不出画像 |

轻级别必出轻量产出：摸到根因出轻量画像（1 机制图 / 2 洞见 / 2–3 方向）；仅浅聊 / 纯倾诉也出「进展小结」（已梳理什么 + 一个可试方向），保证不白聊。

## 二、聊到根因的判断标准（出画像前强制自检）

三条全过才允许出画像；任何一条不过 → 回到根因挖掘继续聊，或到期出进展小结：

1. **压力源已具体化**：不再是「压力大」「最近事多」这类笼统说法，而是能说出具体的一件事、一段关系、或一个反复出现的模式；
2. **情绪模式已识别**：能说出「什么场景触发 → 身体什么反应 → 我通常怎么应对」这条链，而不只是零散的情绪词；
3. **有增量洞察**：画像里「新洞见」至少有一条是对方**没直接说过**的、从聊天里用心理学框架推理出来的重新框定——纯复述对方原话不算增量。

未到根因时的引导话术（示例）：「画像现在出的话，基本就是把你说过的整理一遍，没什么用。咱们再往下挖一层——你说压力大的时候，最先冒出来的是哪件事？挖到根上，画像才有真东西。」

## 三、画像的结构铁律（单页信息图，不可退化成总结/卡片流）

情绪画像**不是聊天总结**，是临床心理学的「个案概念化」产物，且必须是一份**能一眼看懂的单页信息图**。模板强制以下结构，缺一项即不合格：

| 强制项 | 要求 |
|:---|:---|
| **统领封面** | 文件级主标题「情绪画像」必须醒目（非 14px 小标签），配副标题 + 日期 + 框架来源标签 |
| **首屏概览** | 顶部必须有一个「一眼结论」+ 3–4 个**由本案例实际呈现维度动态生成**的状态条（不固定为焦虑/睡眠/工作/希望；维度从 5-P 与症状谱系抽最关键者，如 grief 案例→悲伤/功能/关系/意义；relationship 案例→冲突/依恋/沟通/孤独） |
| **单一叙事主轴** | 左脊编号节点串起 7 段：概念化→谱系→机制图×3→重新框定→可试方向，有视觉动线，不拼贴 |
| **语义配色** | 红=卡住/风险、蓝=机制/认知、绿=行动/保护，配色编码含义而非装饰 |
| **5-P 个案概念化** | 6 格全填，Perpetuating 标出杠杆点 |
| **≥1 个实证框架** | 必须套真实心理学框架（Job Strain/Karasek、失眠认知模型/Harvey、承诺升级/Staw、ACT 认知融合、依恋理论等），不可只做朴素归纳 |
| **症状谱系定位** | 按公认维度（依呈现症状选用焦虑/睡眠/职业/关系/意义等）归类，对照 NIMH 及 GAD-7/PHQ-9/PSS 等公认筛查工具描述，但**不贴诊断标签** |
| **机制 SVG** | 核心机制至少 1 张可交互 SVG（循环图/象限图/环路图），让对方「看见」机制而非读文字 |
| **新洞见 ≥2 条** | 每条必须是对方没说出口的重新框定（套框架后推出的新视角），复述不算 |
| **可试方向说人话** | 第一条必须是「今天就能做的一件」（最低门槛动作），其余按优先级；每条 = 做法 + 一句大白话原理 + 出处 |
| **双模板自动分层** | 对话达根因且模式信号强 → 概念化版（5-P+机制图+新洞见）；达根因但偏倾诉/未达模式层 → 叙事性回望版（`report_narrative_template.html`）。由 `check_readiness.py` 判定，AI 不自由裁量 |

> 适用人群提醒：本 skill 主力人群是「问题已有些严重、但不愿找心理医生」的人。画像必须有**临床概念化底**，且**信息图必须本人自省可读**——给出的重新框定要有心理学依据、版式要一眼看懂，不能像朋友闲聊的归纳，也不能像论文。

## 四、分级深度（画像厚度按级别）

| 级别 | 画像深度 |
|:---|:---|
| 轻 | 机制图 1 张，洞见 2 条，可试方向 2–3 条；最轻量，但**必出**（摸到根因出轻量画像，仅浅聊出进展小结），不白聊 |
| 中 | 机制图 2 张，洞见 2–3 条，可试方向 3–4 条 |
| 重 | 机制图 2–3 张，洞见 3–4 条，可试方向 4 条；机制密度最高，且**接收度铺垫最足**（见五） |

同一模板，靠填充密度区分，不换结构。

## 五、接收度设计（重但不愿就医人群怎么接得住）

画像不是扔给对方就完。生成与呈现时注意：

- **首屏「一眼结论」用接得住的语气**：不堆术语，先给一个对方能点头的大白话框架（如「你不是心态不行，是坐在一个高要求低决策权的位置里」）；
- **机制 + 行动平衡**：先 Rationale（我卡哪/为什么）再 Action（第一个能动的动作），不跳过机制直接给方法，也不只分析不给出口；
- **洞见不炫技**：每条链一个框架、一句人话，不写「根据 XX 理论的 XX 维度」式学术腔；
- **不替对方下结论**：谱系只做维度归类，不写「你得了」；
- **可试方向第一条必须是「今天就能做的一件」**：重人群决策能耗高，需要最低门槛动作破冰。

## 六、画像后闭环（出完画像对话怎么续）

画像是收敛终端，但不是对话终点。出完画像后：

- **先接住「知道根因」的冲击**：看清自己卡在哪，有时先让人难受一下，不是立刻轻松。出完画像先一句接住（「看清楚这些，可能会有点沉，正常」），再进入下面的反应空间；
- 给用户反应空间：**不问「看懂没」**，而是「哪一条你最想接着聊，或者最不服？」；
- 对方质疑某条洞见 → 回到根因挖掘就那条深聊，不辩护；
- 对方想据此行动 → 可就「今天就能做的一件」拆成下一步，或协助列清单；
- 对方情绪在画像后明显下沉 → 当场风险重评（§5），必要时升危机模式；
- 对话结束前，确认是否要本地落盘（先征得同意，隐私红线 §0/§7.4）。

SKILL.md §2 流程已含「产出画像」节点，画像后接续动作见本段。

## 七、怎么填 HTML 模板（report_template.html）

模板用 `{{token}}` 占位，AI 替换后交付。

- **封面**：`情绪画像` 四字保留作主标题；`{{cover_sub}}` 写自省定位；`{{date}}` + 框架来源标签。
- **首屏概览**：`{{hero_insight}}` 写一眼结论；`{{gauge_X}}` / `{{gauge_X_pct}}` 填 0–10 与百分比。
- **5-P 六格**：逐格填；Perpetuating 句末保留「← 杠杆点在这」。
- **症状谱系**：4 个维度，用「倾向 XX 谱系」「符合 XX 模型描述」措辞，不写「你得了」。
- **机制 SVG（重点）**：
  - AI 选最贴合框架，画完整 `<svg>` 粘到 `{{mechN_svg}}`；机制图 1 必出，2–3 按级别补。
  - **禁止用 `<b>` 包裹 SVG 内文字**——SVG 命名空间不渲染 HTML `<b>`，会导致文字消失（只有框没字）。要粗体给 `text` 加 `font-weight="700"` 或套 `.flow-t` 类（模板已加粗）。
- **新洞见**：`{{洞见N}}` ≥2 条，每条链一个框架，非复述。
- **可试方向**：第一条 `{{方向1}}` = 今天就能做的一件；其余按优先级，主体日常语言。

## 九、写法红线（去医感 + 免责 + 热线）

- 用「可能 / 似乎 / 大概」，不写「你得了 / 你是 XX 症」。
- 不给标签，不替用户下结论；谱系定位只做「维度归类」不诊断。
- 所有机制/框架/干预引用须按 §3（SKILL.md）挂白名单出处，出口前跑 `check_rag.py` 自检。
- 可试方向链到实证框架或 `practices.md` 练习，不凭空开方法；主体说人话。
- 情绪描述只用日常语言，类比生活场景，不抄量表条目。
- **模板底部免责声明一字不差**；热线 `12356` / `010-82951332` / `800-810-1117` 原样出现（`check_safety.py` 会校验）。
- 画像须含 ≥1 个实证框架名 + ≥2 条新洞见（机器校验项，见 SKILL.md §7.6）。
