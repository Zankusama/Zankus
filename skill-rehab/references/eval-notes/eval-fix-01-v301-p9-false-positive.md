# case-04 · v3 评估器自举 p9 假阳性修复（2026-08-03）

## 症状

v3 评估器跑 skill-rehab 自举 96/100 S（p9 失 4 分）：
- `p9.fence_escape` 0/2 ❌：报告"围栏内 $ 提示符 0 处（>0）或围栏数<2"——awk 检测围栏 2 块、$ 提示符 0 行（实际没问题），但 v3 评估器用 `re.findall(r'```[^\n]*\n(.*?)\n```')` 严格正则只抓到 1 块（SKILL.md 实际只有 1 个 ` ```bash ` 围栏）
- `p9.fuzzy_placeholder` 0/2 ❌：报告"模糊占位符 2 处（>0）"——SKILL.md 第 76 行「模糊占位符」、第 115 行「命令占位符」是描述术语本身，被关键词「占位符?」（`占位`+0-1 个「符」）误伤

## 分级

**基本型**（v3 是新维度，不修等于自举无法满分）

## 修法选项（按机制给，不按格式给）

1. **修 v3 评估器** min_fence_count 2→1（围栏 1 也能查 $ 提示符，参数更合理）+ 关键词「占位符?」→「占位符\b」（必须含「符」+ 词边界，避免「占位词」等假阳性）—— 采纳
2. 改 SKILL.md 加 1 个合法围栏（满足 min=2）—— 凑数，不优雅
3. 改 SKILL.md 避开「占位符」关键词（描述行改名）—— 已采纳一部分（76 行「占位词」、115 行「命令示例」）
