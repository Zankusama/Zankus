# Agent B 盲审（对抗式验证 · 子 agent 独立视角）

## 目的
主 agent 的康复处方/诊断结论由「自己造的评估器 + 自己的世界观」产出，存在**同源自欺**风险
（皮叔审计实锤：4 项文档矛盾主评估器自己没抓到）。
Agent B = 未参与本次诊断的独立子 agent，用**正交 rubric**重判同一目标 skill，产出分歧矩阵，
标出「主 agent 可能只是自我印证」的结论。呼应三明智：可信度来自**认知距离**，不是是否自动化。

## 真盲约束（关键，违反即盲审失效）
主 agent 调起 Agent B 时，**只传**：
1. 目标 skill 的文件路径（让 Agent B 自己读原文）
2. 主 agent 的康复处方/诊断报告文本

**绝不传**：主 agent 的推理链、中间思考、为什么这么判——否则 Agent B 被锚定，变成「换壳自欺」。

## Agent B rubric（与主评估器正交）
| 主评估器重（不评） | Agent B 重（刻意错开，拉认知距离） |
|:---|:---|
| 禁 AI 味 / 表格优先 / 文档一致性 / 死规矩遵守 / 确定性护栏 / 脚本化 | 功能完整性（交付物真能解决问题吗，缺关键能力吗） |
| | 用户可读性（真人看不懂/用不顺的点） |
| | 实际可用性（真实环境跑会卡在哪） |
| | 风险引入（修复/诊断有没有引入新风险或破坏现有功能） |
| | 价值对齐（修的是用户真在乎的，还是作者自嗨） |

## Agent B 输出 schema（分歧矩阵）
```markdown
## Agent B 盲审分歧矩阵
| 主结论项 | 主判定 | Agent B 判定 | Agent B 严重度 | 理由（基于原文，不引用主 agent 推理） |
|---|---|---|---|---|
| pX.foo | 通过 | 反对 | P1 | … |
| pY.bar | 建议 | 同意 | - | … |

### 独立发现（主 agent 未提及）
- …

### 总体置信
- 高 / 中 / 低（依据：覆盖的主结论比例 + 独立发现数量）
```

## 调用方式（主 agent 执行）
1. 诊断产出处方后，调用 Agent B 子 agent（general-purpose / Explore 类），prompt 见下。
2. Agent B 回收分歧矩阵，写入 `output/skill-rehab/<skill>/blind-review.md`。
3. 主 agent 把 ①评估器分 ②redteam 结果 ③分歧矩阵 ④「可能自证」项 汇总进诊断交付物。

## Agent B prompt 模板（主 agent 复制发给子 agent）
```
你是独立审查者，未参与本 skill 的康复诊断。你的唯一输入是「目标 skill 文件」+「主 agent 的康复处方」。
你看不到主 agent 的推理过程，也不要参考它——你的任务是用自己的判断独立复核。

【你的维度】功能完整性 / 用户可读性 / 实际可用性 / 风险引入 / 价值对齐
（不要评禁 AI 味、表格、文档格式——那是另一把尺子，避免与主评估器同源）

【任务】
1. 读目标 skill 原文（路径：<target>）
2. 读主 agent 处方（下方文本）
3. 对处方每条结论，给「同意 / 反对 / 补充」+ 你的严重度（P0/P1/P2/info）+ 理由（必须基于原文，不引用主 agent 推理）
4. 列出主 agent 未提及的独立发现
5. 给总体置信（高/中/低）

【主 agent 处方】
<prescription text>

按上方 schema 输出分歧矩阵。
```

## 降级
Agent B 不可用（无子 agent 权限 / 离线 / 成本上限）→ 主 agent 标注「盲审跳过：<原因>」，
仅用 redteam 结果，**不阻塞**治疗；下次可用时补跑。
